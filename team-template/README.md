# 팀 공유 작업공간 템플릿

이 폴더에는 현재 컴퓨터의 기존 작품이 포함되어 있지 않습니다.

새 작품을 공유하기로 합의했을 때 아래 구조를 복사해 사용합니다.

```text
team-template/
├── components/     기능별로 분리한 .tox
├── scripts/        Python
├── shaders/        GLSL
├── assets/         공유가 허용된 미디어만 저장
├── previews/       리뷰용 이미지/짧은 영상
└── PROJECT.md      실행 방법과 장비 설정
```

실제 파일을 올리기 전 루트 `.gitignore`에 해당 경로를 명시적으로 허용해야 합니다. 예를 들어 이 템플릿 안에서 새 프로젝트를 공유한다면 `!/team-template/**` 규칙 덕분에 파일이 표시됩니다.

`.toe` 파일은 동시에 한 명만 편집하고, 가능하면 각 기능을 `.tox`, Python, GLSL로 나눕니다. 대용량 파일을 처음 추가하기 전 세 사람 모두 Git LFS를 설치해야 합니다.
